# Scalar API Documentation Guide

## How to Regenerate Scalar API Documentation

Scalar automatically generates API documentation from your OpenAPI specification. Here's how to update it:

### Method 1: Using Scribe (Recommended)

You have Scribe installed which can generate OpenAPI documentation from your code annotations.

```bash
# Generate API documentation
php artisan scribe:generate

# This will create/update the OpenAPI spec that Scalar uses
```

### Method 2: Clear Cache and Reload

```bash
# Clear all caches
php artisan cache:clear
php artisan config:clear
php artisan route:clear

# Then visit your Scalar documentation
# ${APP_URL}/scalar
```

### Method 3: Manual OpenAPI Specification

Create or update `public/docs.openapi.json` with your API specification.

## Accessing Scalar Documentation

Once your API is running, visit:
```
${APP_URL}/scalar
```

## Adding API Documentation to Controllers

To properly document your API endpoints for Scalar/Scribe, add PHPDoc annotations:

### Example: Repository Controller

```php
/**
 * @group Repository Management
 * 
 * APIs for managing GitHub repositories
 */
class RepositoryController extends Controller
{
    /**
     * List all repositories
     * 
     * Get a list of all connected GitHub repositories with their current status.
     * 
     * @response 200 {
     *   "success": true,
     *   "data": [
     *     {
     *       "id": 1,
     *       "name": "laravel",
     *       "full_name": "laravel/laravel",
     *       "status": "completed"
     *     }
     *   ]
     * }
     */
    public function index(): JsonResponse
    {
        // ...
    }
}
```

## Scribe Configuration

Your Scribe configuration is in `config/scribe.php`. Key settings:

```php
'routes' => [
    [
        'match' => [
            'prefixes' => ['api/*'],  // Document all /api/* routes
        ],
    ],
],
```

## Quick Commands

```bash
# Generate documentation
php artisan scribe:generate

# Clear documentation cache
rm -rf .scribe

# Regenerate from scratch
php artisan scribe:generate --force

# View routes
php artisan route:list
```

## Customizing Scalar Appearance

Edit `config/scalar.php`:

```php
'configuration' => [
    'theme' => 'laravel',  // or 'deepSpace', 'purple', etc.
    'darkMode' => true,
    'layout' => 'modern',
]
```

## OpenAPI Specification Location

Scalar looks for the OpenAPI spec at:
- `/docs.openapi` (configured in `config/scalar.php`)
- This is typically generated by Scribe at `public/docs/openapi.yaml`

## Troubleshooting

### Documentation not updating?

1. Clear all caches:
```bash
php artisan optimize:clear
```

2. Regenerate Scribe docs:
```bash
php artisan scribe:generate --force
```

3. Check if routes are registered:
```bash
php artisan route:list | grep api
```

### Scalar page not loading?

1. Check if Scalar is installed:
```bash
composer show scalar/laravel
```

2. Verify configuration:
```bash
php artisan config:show scalar
```

3. Check the path:
```
${APP_URL}/scalar  (default path)
```

## Best Practices

1. **Add @group annotations** to organize endpoints
2. **Add @response examples** for each endpoint
3. **Document request parameters** with @bodyParam
4. **Add descriptions** to all public methods
5. **Regenerate after changes** with `php artisan scribe:generate`

```php
     *     "question": ["The question field is required."]
     *   }
     * }

```
