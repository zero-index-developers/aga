# 🚀 How to Run the AGA Project

## **Quick Start (Recommended - Using Docker)**

### **Step 1: Set up environment variables**
```bash
# Copy the environment file
cp .env.example .env
```

### **Step 2: Start all services with Docker**
```bash
# Start database, API, and client in one command
docker-compose up -d
```

This will start:
- ✅ **PostgreSQL Database** on port 5433
- ✅ **Laravel API Backend** on port 8000
- ✅ **Next.js Frontend** on port 3000

### **Step 3: Install API dependencies**
```bash
docker-compose exec api composer install
```

### **Step 4: Configure Laravel**
```bash
# Copy API environment file
docker-compose exec api cp .env.example .env

# Generate application key
docker-compose exec api php artisan key:generate
```

### **Step 5: Set up database**
```bash
# Run migrations
docker-compose exec api php artisan migrate
```

### **Step 6: (Optional) Add GitHub Token**
Edit `api/.env` and add your GitHub token for repository analysis:
```env
GITHUB_TOKEN=ghp_your_github_token_here
```

**Get GitHub Token:**
1. Go to https://github.com/settings/tokens
2. Generate new token (classic)
3. Select scope: `repo` or `public_repo`
4. Copy token to `api/.env`

### **Step 7: Start queue worker (for background jobs)**
```bash
docker-compose exec api php artisan queue:work &
```

### **Step 8: Access the application**
- 🌐 **Frontend**: http://localhost:3000
- 🔧 **API**: http://localhost:8000
- 🗄️ **Database**: localhost:5433

---

## **Useful Docker Commands**

```bash
# View logs
docker-compose logs -f

# View specific service logs
docker-compose logs -f api
docker-compose logs -f client

# Stop services
docker-compose down

# Rebuild containers
docker-compose up -d --build

# Access API container shell
docker-compose exec api bash

# Access client container shell
docker-compose exec client sh

# Access database
docker-compose exec database psql -U aga_user -d aga_db
```

### **Prerequisites:**
- PHP 8.3+
- Node.js 20+
- PostgreSQL 16
- Composer

### **Backend (API):**
```bash
cd api
composer install
```

### **Frontend (Client):**

Edit `.env` and change ports:
```env
DB_PORT=5434
CLIENT_PORT=3001
```

```bash
# Check database status
docker-compose ps

docker-compose restart database
```

```bash
# Rebuild containers
docker-compose down
docker-compose up -d --build
```
