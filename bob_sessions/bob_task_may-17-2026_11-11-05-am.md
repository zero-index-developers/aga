## 🚀 Running the Project

### Prerequisites
- Docker and Docker Compose installed on your system

### Steps to Run:

1. **Create environment file:**
   ```bash
   cp .env.example .env
   ```

2. **Start all services with Docker Compose:**
   ```bash
   docker-compose up -d
   ```

   This will start three services:
   - **PostgreSQL Database** (port 5433 → 5432)
   - **Laravel API** (port 8000)
   - **Next.js Client** (port 3000)

3. **View logs to monitor startup:**
   ```bash
   docker-compose logs -f
   ```

4. **Run database migrations (after containers are up):**
   ```bash
   docker-compose exec api php artisan migrate
   ```

5. **Access the application:**
   - **Frontend:** http://localhost:3000
   - **Backend API:** http://localhost:8000
   - **Database:** localhost:5433

### Additional Commands:

**Stop services:**
```bash
docker-compose down
```

**Rebuild containers:**
```bash
docker-compose up -d --build
```

**View specific service logs:**
```bash
docker-compose logs -f client  # Frontend logs
docker-compose logs -f api     # Backend logs
docker-compose logs -f database # Database logs
```

**Access container shell:**
```bash
docker-compose exec api sh      # API container
docker-compose exec client sh   # Client container
```

## Prerequisites
- **PHP 8.3+** with extensions: PDO, PostgreSQL, mbstring, zip, bcmath, gd
- **Composer** (PHP package manager)
- **Node.js 20+** and npm
- **PostgreSQL 16** database server

## Setup Steps

### 1. Database Setup
Install and start PostgreSQL, then create database:
```sql
CREATE DATABASE aga;
CREATE USER postgres WITH PASSWORD 'admin';
GRANT ALL PRIVILEGES ON DATABASE aga TO postgres;
```

### 2. Backend (Laravel API)
```bash
cd api
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
composer run dev
```
API runs at: http://localhost:8000

### 3. Frontend (Next.js Client)
Open new terminal:
```bash
cd client
npm install
cp .env.example .env
npm run dev
```
Frontend runs at: http://localhost:3000

## Quick Alternative
If you have **PHP and Composer** installed, the Laravel backend has a convenient setup script:
```bash
cd api
composer run setup  # Installs dependencies, generates key, runs migrations
composer run dev    # Starts all services (API, queue, logs, vite)
```

The [`composer.json`](api/composer.json:41-52) includes automated setup and dev scripts that handle most configuration.
